начална структура на приложението и проектирана и създадена начална база данни.

- [ ] Написан увод в предоставения шаблон на документацията.

- [x] Проектирана и реализирана начална схема с entities, миграция и ER диаграми.
- [ ] Потвърдено създаване на началната development база чрез миграциите и ръчна проверка във Visual Studio/SSMS. Успешните disposable тестови бази не потвърждават тази стъпка.
- [x] Създадено GitHub хранилище: https://github.com/IvoShomov2/DishDrop.

## Реализирана техническа основа

- [x] Един solution с Web, Data, Core, UnitTests и IntegrationTests.
- [x] .NET 10, начална MVC/Identity интеграция и CI.
- [x] Модел за потребители, ресторанти, staff, куриери и райони.
- [x] Менюта, категории, варианти, опции и allergens.
- [x] Количка, поръчки/snapshots, плащания, доставки и histories.
- [x] Отзиви/отговори, поддръжка, известия и audit модел.
- [x] ApplicationUser и адаптирани Register/Manage страници.
- [x] Атрибути и DataConstants плюс Fluent API в DbContext; checks, FK/unique индекси и rowversion.
- [x] Запазена Identity миграция и AddInitialBusinessSchema migration.
- [x] Идемпотентен SQL script, изпитан двукратно.
- [x] Изрично справочно/demo seeding без hardcoded пароли.
- [x] Реални SQL Server LocalDB проверки: 42 DB теста + 4 HTTP и 2 metadata теста без база.
- [x] Традиционен entity/DbContext стил и изрично mapped обратни navigation properties.
- [x] Техническа документация, спецификация и ER диаграми в хранилището.

Отчетената локална проверка е Release build с 0 warnings/errors и 40 успешни
integration теста, 0 skipped. UnitTests няма бизнес тестове; няма твърдение
за бизнес coverage. Локалните SQL проверки са върху LocalDB 15.0.4382.1.

GitHub CI за commit `45bdd38` е изпълнен успешно: както `build-and-test`,
така и `sql-server-integration` с отделен SQL Server 2022 контейнер.
Резултат: https://github.com/IvoShomov2/DishDrop/actions/runs/43653724491.
Този резултат се отнася за посочения commit; следващите промени се проверяват отново.

Одобрението от консултанта и ръчната проверка на development средата остават
за потвърждение. Наличните entities, enum стойности и индекси не са реализация
на бизнес услугите.

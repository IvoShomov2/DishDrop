# План за разработка

## Настояща задача

- [x] Един solution с Web, Data, Core, UnitTests и IntegrationTests.
- [x] Преместване на контекста и съществуващите Identity миграции в Data.
- [x] Запазване на MVC/Identity конфигурацията и началния дизайн.
- [x] Release build, integration smoke тест без база и начална CI конфигурация.
- [x] Документация за архитектура и разработка.

Локалните проверки са успешни. Workflow още не е изпълнен в GitHub.
Няма бизнес тестове, създадена бизнес база или одобрение от консултант.

1. Модел за потребители, ресторанти, доставчици и райони.
2. Модел за менюта.
3. Модел за поръчки и доставки.
4. Отзиви, поддръжка и известия.
5. Общ преглед, начална миграция и реална SQL Server проверка.
6. Demo данни и подготовка за Етап 1.

Тези задачи не са започнати с настоящата структурна промяна.
При бъдещата начална бизнес миграция трябва да се съобрази запазената
Identity миграция; тя не се изтрива или заменя автоматично.
